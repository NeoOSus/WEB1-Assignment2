# Assignment 2: Flexbox and CSS Grid

This is a simple website for Web Technologies Assignment 2.

Before submitting, add your name and group:

- Student: Your full name
- Group: Your group

## Files

- `index.html` — home page and navigation
- `cards.html` — Task 1, cards with Flexbox
- `grid.html` — Task 2, page layout with Grid areas
- `gallery.html` — Task 3, image gallery with CSS Grid
- `portfolio.html` — Task 4, portfolio with Grid and Flexbox
- `style.css` — styles for all pages

## Open the website

Open `index.html` in a browser. Images are loaded from the internet.

## Publish with GitHub Pages

1. Upload these files to a GitHub repository.
2. Open the repository Settings and choose Pages.
3. Select the `main` branch and the root folder, then save.
4. Use the link shown in the Pages section.

There is no build command because the website only uses HTML and CSS.
